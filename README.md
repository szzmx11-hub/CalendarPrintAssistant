# SCM 自动寻边 V9.1.0

本版本恢复 V8 完整泊坞窗操作方式，并由 V9.1.0 64 位 C++ 原生插件执行产品外形、外形加孔位及复检。

发布要求：只有 Windows 构建、两组引擎测试全部通过，并生成文件版本为 `9.1.0` 的
`SCMAutoContourNative64.cpg` 后，才允许生成一键安装 ZIP。仓库中不保存或冒充旧版 CPG。

主要修复：

- V8 外形、内部、内外同时、圆孔、精度设置、进度和中文状态界面恢复；
- 面板直接调用无弹窗的 V9.1.0 原生命令；
- Ceres 连接点移动限制为 0.75 像素，防止直线交点被拉出十几个像素；
- 小于半像素的抗锯齿尖角补偿不再误报 `invalid`；
- 复检错误以 UTF-8 中文回传到泊坞面板；
- 安装器会删除旧 V8/V9 面板，仅保留一个最新版。
